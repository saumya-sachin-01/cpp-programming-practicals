# C and C++ Programming Lab

## About 

This repository contains a comprehensive collection of C and C++ programming practicals developed as part of academic coursework. The programs are organized according to the syllabus and cover a wide range of concepts from basic programming to advanced object-oriented techniques.

The repository begins with fundamental C concepts such as dynamic memory allocation and gradually progresses to C++ programming, object-oriented programming, file handling, templates, STL, and exception handling.

---

## Syllabus Coverage

### 1. C Programming Concepts

* Dynamic Memory Allocation (`malloc`, `calloc`, `realloc`, `free`)
* Structures and their limitations
* Need for Object-Oriented Programming

---

### 2. C++ Programming Basics

* Introduction to Object-Oriented Programming
* Input/Output using `cin` and `cout`
* Data types and type conversions
* Manipulators (`setw`)

---

### 3. Objects and Classes

* Class and object implementation
* Constructors and types of constructors
* Objects as function arguments
* Returning objects from functions
* Difference between structures and classes

---

### 4. Arrays and Strings

* Arrays as class members
* Arrays of objects
* String handling
* Standard C++ string class

---

### 5. Polymorphism

* Function overloading
* Operator overloading (unary and binary)
* Data conversion
* Use of keywords like `explicit` and `mutable`

---

### 6. Inheritance

* Concept of inheritance
* Base and derived classes
* Constructors in derived classes
* Types of inheritance
* Aggregation

---

### 7. Advanced Functions

* Inline functions
* Virtual functions
* Friend functions
* Static functions
* `this` pointer
* Dynamic type information

---

### 8. File Handling and I/O Streams

* Stream classes and errors
* File input/output using streams
* File pointers
* Operator overloading for I/O
* Command line arguments

---

### 9. Templates and Exceptions

* Function templates and class templates
* Exception handling (`try`, `catch`, `throw`)
* Multiple catch blocks
* User-defined exceptions

---

## How to Run

### For C Programs

```bash id="c1a2b3"
gcc filename.c -o output
./output
```

### For C++ Programs

```bash id="c4d5e6"
g++ filename.cpp -o output
./output
```
